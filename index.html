사용법 보기

① 시교 등록하기

홈 화면 우측 하단 + 버튼을 눌러 품목을 고르고 SEG·제품/시교명·지역·성함을 입력하면 등록돼요. 파종일·정식일·대비품종·밭 주소(최대 5개)는 몰라도 등록 자체는 가능해요. 홈 검색은 제품명·SEG·지역·성함까지 다 찾아줘요.

② 사진 등록하기

시교 상세의 "타임라인" 탭 맨 위 사진 추가를 누르면 사진첩에서 고르거나 바로 촬영할 수 있어요. 촬영일자는 자동으로 오늘 날짜(한국 시간 기준)가 들어가고, 세로로 찍은 사진의 회전도 자동으로 바로잡혀 저장돼요.

③ 성장 비교 / 품종 비교

시교 상세의 "성장비교" 탭에서는 같은 시교의 사진 2~4장을, 하단 "비교" 탭에서는 품목·품종 상관없이 아무 시교끼리나 골라 비교할 수 있어요. "가로로 크게 보기"로 확대·이동해서 볼 수 있고, "이 비교 저장하기"를 누르면 지금 비교 화면을 한 장의 이미지로 합쳐 따로 모아둘 수 있어요 (저장된 항목은 길게 눌러 삭제).

④ 사진 마킹하기

사진을 탭해서 크게 연 뒤 마킹을 누르면 병해충 발생 부위 등에 원·화살표·선·글자로 표시할 수 있어요. 원·화살표·글자는 그린 뒤에도 손잡이로 위치와 크기를 조절하고 확인 버튼을 눌러야 최종 반영돼요. 마킹한 사진은 원본과 별도로 저장되고, 짧은 코멘트도 남길 수 있어요.

⑤ 사진 길게 눌러 정리하기

타임라인에서 사진을 길게 누르면 선택 모드로 바뀌어요. 사진을 여러 장 고를 수 있고, 화면 아래 나오는 아이콘으로 마킹 · 공유 · 내려받기 · 삭제를 바로 할 수 있어요. 마킹은 사진 한 장만 골랐을 때 됩니다.

⑥ 메모 남기기

"메모" 탭에서 날짜와 함께 생육상태·특이사항을 기록할 수 있어요. 수정·삭제도 자유롭게 가능해요.

⑦ 밭 주소로 바로 길찾기

시교 상세에 밭 주소를 등록해두면(최대 5개), 각 주소 옆 복사 버튼으로 다른 앱에 붙여넣거나 지도 아이콘으로 바로 지도앱을 열어 길찾기 할 수 있어요.

⑧ 작황조사 캘린더

하단 "캘린더" 탭에서 방문 일정을 관리해요. 날짜를 눌러 일정을 등록할 수 있고, 대상은 등록된 시교를 검색해서 고르거나 직접 입력할 수 있어요. 좌우로 스와이프하면 월이 넘어가고, 날짜 칸엔 그날 일정이 최대 3개까지 표시돼요. "캘린더에 추가"를 누르면 구글 캘린더에도 저장해서 그쪽 알림을 받을 수 있고, 설정에서 "오늘 방문 예정 일정 알림"을 켜두면 앱을 열 때 오늘 일정 개수를 알려줘요.

⑨ 팀 공유 (서버 저장)

이 버전은 팀 4명이 같은 서버에 저장해서 함께 보는 방식이에요. 사진·시교 정보는 올리는 즉시 팀원 전체에게 공유되고, 별도 백업이 필요 없어요. 시교 정보 수정·삭제와 본인이 올린 사진 삭제는 PIN 확인이 필요해요.

⑩ 데이터 내보내기 (CSV)

설정의 "전체 시교 목록 CSV로 내보내기"를 누르면 품목·SEG·제품명·지역·성함 등 등록된 모든 시교 정보가 표 파일로 다운로드돼요. 엑셀에서 바로 열어볼 수 있어요.

⑪ 신호 없는 현장에서 사진 저장

사진 저장 중 인터넷이 안 되면 사진이 사라지지 않고 기기에 임시로 저장돼요. 홈 화면 위쪽에 "사진 N장 업로드 대기 중" 배너가 뜨고, 인터넷이 다시 연결되면 자동으로 업로드돼요. 배너를 눌러 바로 재시도할 수도 있어요.
